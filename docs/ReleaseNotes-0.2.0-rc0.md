# StudioMCP 0.2.0 RC0

- Adds 20 tools for native Studio FK/IK, KKPE bones/blendshapes and Timeline tracks/keyframes; 60 tools total.
- Uses the original Studio, KKPE and Timeline editing and save paths. Existing tools and saved data remain compatible.
- Reports bridge validation errors directly to the MCP client.

Update the host and ONE matching game bridge, then refresh the client's tool list. KKPE and
Timeline are optional and are not bundled. See CHARACTER-ANIMATION.md for supported bindings.

KKS live checks covered posing, all ten track kinds, interpolation, scene save/reload and a real
capture with KKPE 2.21.4 and Timeline 1.5.4. The new tools are build-verified only on KK; this is a pre-release.

Previously published as 0.2.0 RC1. This renumbered build retains the same feature baseline with corrected RC0 version metadata.
